# Telegram OTP Bot

A Telegram bot that generates one-time passwords and sends them through an SMTP email account you control.

## Features

- Generate 6-digit OTPs
- Send OTPs through SMTP
- OTP expiration
- One-time verification
- Telegram commands

## Commands

/start
/otp your@email.com
/verify 123456

## Installation

```bash
npm install
